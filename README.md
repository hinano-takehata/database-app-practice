# database-app-practice

## 概要
COACHTECH 教材 Tutorial 9-3「データベース操作ハンズオン演習」で作成した成果物です。
マイグレーション、シーダー、クエリビルダを使って、「商品管理システム」の商品一覧機能を作成した。

## 使用技術
- PHP 8.5
- Laravel 10.5
- MySQL
- マイグレーション、シーダー


## 学んだこと
- マイグレーションファイル内でテーブルの定義の仕方
- シーダーを使ってダミーデータを複数入れる流れ
- コントローラー内で、DB::table()を使い、データ一覧を取得する方法

## 動作確認
http://localhost/products
にアクセスし、完成イメージと同じ5件の商品（商品名、価格、在庫、カテゴリ）が画面に表示されているか確認した。
